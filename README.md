# GAG Hub (с базой данных)

Telegram-бот + мини-приложение. Баланс, питомцы, колесо, кейсы и обмен хранятся на сервере (SQLite, файл `gag.db`).

## Файлы
| Файл | Что это |
| --- | --- |
| `index.html` | Приложение (GitHub Pages) |
| `main.py` | Бот и API-сервер в одном процессе |
| `server.py` | API: база, проверка подписи Telegram, колесо, кейсы, обмен, промокоды |
| `pets.json` | Питомцы по редкостям |
| `launcher.py` | Окно запуска бота |
| `.env.example` | Образец настроек (скопируйте в `.env`) |

## Запуск в PyCharm
1. Откройте папку как проект, создайте venv, выполните `pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN`, `WEBAPP_URL`, `ADMIN_ID` (узнать: `/myid` боту).
3. Запустите `main.py` (или `launcher.py`).

## Самый простой запуск (v3): всё с одного адреса
`main.py` теперь сам отдаёт `index.html` и API с одного адреса, GitHub Pages не нужен.
1. Запустите `main.py`.
2. Откройте туннель: `cloudflared tunnel --url http://localhost:8080`. Он выдаст адрес `https://....trycloudflare.com`.
3. Впишите этот адрес в `.env` как `WEBAPP_URL=https://.../` и перезапустите `main.py`.
4. В Telegram нажмите /start у бота. `API_URL` в `index.html` оставьте пустым.
Если в приложении сверху красная полоса «Нет связи с сервером», значит `main.py` не запущен или адрес устарел (адрес быстрого туннеля меняется при каждом запуске).

## Если API на другом адресе (старый способ)
Приложение на GitHub Pages обращается к вашему серверу, поэтому ему нужен публичный https-адрес.
- Для проверки: `cloudflared tunnel --url http://localhost:8080` даст временный адрес.
- Для постоянной работы: любой хостинг Python (VPS, Render, Railway). Запускайте `python main.py`.

Впишите этот адрес в `index.html`: `const API_URL = 'https://...';` (без слэша в конце), затем загрузите `index.html` на GitHub.

## Админ
Права проверяет сервер по `ADMIN_ID`, а не вкладка. Команды: `/give @user 100`, `/newcode КОД 10 petals 50` или `/newcode КОД 10 case 0`. Промокод игрок вводит во вкладке «Промокод»; код работает один раз на игрока.

## Важно
Токен бота храните только в `.env`. Если он светился в переписке, перевыпустите его в @BotFather (`/revoke`).

## Возможности
Колесо (награда 2→20 Petals за месяц), кейсы (лучший питомец 1%), ивентовые кейсы (Хэллоуин, Новый год), бесплатный кейс по промокоду, коллекция-книга с силуэтами, продажа питомцев и дублей, апгрейдер, обмен между игроками, профиль с уровнем, достижения, таблица лидеров, темы, вкладка «Растения» и «Мутации».

Значения со звёздочкой (*) во вкладках растений и мутаций неточные. Ивентовые кейсы собраны только из питомцев, которые нашлись в источниках и есть в `pets.json`, списки неполные.

## Новое в этой версии
- **Запросы админу:** вкладка «📨 Запрос». Игрок выбирает питомца и пишет ник Roblox, питомец уходит в залог, сообщение приходит в канал (`CHANNEL_ID`) или вам в личку с кнопками «Выдано» и «Отклонить». Кнопки работают только для `ADMIN_ID`. При отклонении питомец возвращается.
  Чтобы получить ID канала: добавьте бота админом канала, он пришлёт ID в личку. Впишите его в `.env` как `CHANNEL_ID=-100...`.
- **Рефералка:** ссылка в «Профиль». Новый игрок и пригласивший получают по бесплатному кейсу со всеми питомцами (один раз, только для новых игроков).
- **Напоминание:** бот пишет, когда колесо снова доступно.
- **Статистика** во вкладке «Админ» (видна только админу, проверка на сервере).

Важно: Petals нельзя продавать за деньги или Robux. Если игроки смогут купить Petals, а потом получать питомцев в Roblox, это превратится в азартную игру на реальные ценности.

Ваш файл `gag.db` остаётся прежним: новые столбцы добавятся автоматически при запуске.

## Канал обменов
Вкладка «📢 Канал»: игрок выбирает, что отдаёт (из коллекции) и кого хочет, объявление публикуется в канал `TRADE_CHANNEL_ID` с кнопкой «Предложить обмен». Нажавший пишет боту своё предложение, бот пересылает его автору. Сам обмен питомцами игроки делают через вкладку «Обмен» или договариваются сами. Бот должен быть админом канала.

## Способности питомцев
`abilities.json`: описания встроены в `index.html`. Поиск по способностям работает в каталоге. У 128 питомцев описаний нет.

## v4: что нового
- **Новые кейсы:** «Копилка», «Счастливый», «Золотой», «Радужный». В них выпадают монеты Petals, иногда меньше цены кейса, и питомцы. Шансы в окне кейса показаны честно и совпадают с реальными (лучший питомец в Золотом и Радужном 0,01%).
- **Реферальный код:** у каждого игрока свой код в «Профиль». Друг может ввести код один раз за всё время. Приглашающий получает бесплатный кейс и бонус-вращение колеса, друг получает бесплатный кейс.
- **Профиль:** рамка аватара по уровню, история обменов с отзывами 👍/👎 и репутацией, жалобы админу.
- **Росточек:** талисман-экскурсовод, показывает вкладки при первом запуске. Кнопка ❓ слева внизу вызывает его снова.
- **Праздничные эффекты:** конфетти и звуки при выпадении Legendary и выше.
- **Админ** (проверка на сервере): рассылка, бан/разбан, жалобы, активность по дням с графиком, подозрительные аккаунты, акция «×N Petals с колеса», расписание тем по датам, тема для всех, журнал действий.
- **Команды бота для админа:** `/broadcast текст`, `/ban @user`, `/unban @user`, `/export` (CSV игроков), `/give`, `/newcode`.
- **Защита:** лимит запросов (антиспам), копия базы раз в 6 часов в папку `backups/` (последние 20), журнал сервера `server.log`.

## v5: что нового
- **Темы с украшениями:** каждая из 13 тем (зима, весна, лето, осень, Хэллоуин, Новый год, 8 Марта, Пасха, День влюблённых, Св. Патрика, день рождения игры, космос, радуга) теперь добавляет падающие или плывущие частицы, гирлянду под шапкой, полоску внизу, значки на карточках и аватаре и цветное свечение фона. Кнопка ✨ вверху выключает украшения только у этого игрока.
- **Админ управляет темами:** «Включить у всех» задаёт общую тему, «Скрыть выбор тем у всех игроков» убирает вкладку «Темы» без смены темы. Пока что-то из этого включено, вкладку никто не видит.
- **Апгрейдер с колесом:** зелёная зона показывает шанс, стрелка вращается и останавливается по результату сервера (результат считает сервер, анимация только показывает его). Шанс можно выбрать ползунком или кнопками 75/50/25/10/5%, приложение предложит подходящих питомцев. Ставку можно быстро выставить кнопками ×1, ×2, ×5 и «Максимум».
- **Подсказки имён:** в полях «что ставлю», «что отдаю» и «питомец из коллекции» сначала идут питомцы, которые есть у игрока (с количеством), потом остальные.
