# GAG Hub

Telegram-бот с мини-приложением для Grow a Garden: ежедневное колесо, кейсы за Petals, коллекция, каталог питомцев и калькулятор трейда.

Petals и питомцы существуют только внутри приложения. Их нельзя купить, обменять или вывести в игру.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Само приложение (публикуется на GitHub Pages) |
| `main.py` | Telegram-бот (запускается на вашем компьютере) |
| `launcher.py` | Окно управления для запуска и остановки бота |
| `.env.example` | Образец настроек. Копия `.env` с вашими значениями в GitHub не загружается |

## 1. Перед публикацией

1. Если токен бота когда-либо лежал в коде или в переписке, откройте @BotFather → `/revoke` и получите новый.
2. Токен хранится только в файле `.env` на вашем компьютере. В репозиторий он не попадает (см. `.gitignore`).

## 2. Публикация на GitHub Pages

1. На github.com нажмите **New repository**, назовите его `gag-hub`, выберите **Public** (на бесплатном тарифе Pages работает только с публичными репозиториями), галочки README и .gitignore не ставьте.
2. На странице нового репозитория выберите **uploading an existing file**, перетащите `index.html`, `main.py`, `launcher.py`, `README.md`, `.gitignore`, `.env.example`, `requirements.txt` и нажмите **Commit changes**. Файл `.env` не загружайте.
3. Откройте **Settings → Pages**. В блоке *Build and deployment* выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
4. Через минуту-две вверху страницы появится адрес вида `https://ВАШ-НИК.github.io/gag-hub/`. Это адрес приложения.

То же через командную строку:

```bash
git init
git add .
git commit -m "GAG Hub"
git branch -M main
git remote add origin https://github.com/ВАШ-НИК/gag-hub.git
git push -u origin main
```

## 3. Настройка бота

1. Скопируйте `.env.example` в `.env` и впишите значения:
   - `BOT_TOKEN`: токен от @BotFather;
   - `WEBAPP_URL`: адрес из шага 2.4 (со слэшем в конце);
   - `ADMIN_ID`: ваш числовой Telegram ID. Запустите бота, отправьте ему `/myid` и вставьте число.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Запустите `python launcher.py` и нажмите «Запустить бота» (или `python main.py`).
4. В `index.html` впишите `BOT_USERNAME` (юзернейм бота без @). Это нужно для кнопки «Подарить» в админ-вкладке. После правки загрузите файл в репозиторий ещё раз.

## 4. Админ-функции

- Вкладка «Админ» видна только аккаунту `@minekrafter29` (`ADMIN_USERNAME` в `index.html`). Это удобство, а не защита: настоящая проверка прав делается в боте по `ADMIN_ID`.
- Подарок игроку: вкладка «Админ» или команда боту `/give @username 100`. Игрок должен хотя бы раз нажать `/start`.
- Баланс и коллекция хранятся в браузере игрока на его устройстве, поэтому Petals не переходят между устройствами. Для общей базы нужен сервер.

## 5. Как добавить описания питомцев

В `index.html` найдите блок `const ABILITY = {};` и добавляйте строки вида `ABILITY['Dog'] = 'Что делает питомец';`. Кнопка «?» в каталоге покажет это описание.
